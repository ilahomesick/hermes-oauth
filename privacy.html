Privacy Policy

Last updated: 27 October 2026

This policy covers the Hermes Agent Google Workspace integration ("the application"). The application is a personal automation tool operated by a single individual on their own computer. It is not a commercial service and it has no users other than its operator.

1. What the application accesses

Only after the account holder grants consent through Google's OAuth screen, and only for the account holder's own Google account, the application requests:

  • Gmail — read, modify (labels) and send, to read and draft the owner's own mail.
  • Google Calendar — read, to report the owner's own schedule.
  • Google Drive — read and write, to store and retrieve the owner's own files.
  • Google Docs and Sheets — read and write the owner's own documents and spreadsheets.
  • Contacts — read-only, to resolve names already in the owner's address book.

2. How the data is used

Data is used solely to perform tasks the account holder asked for: summarising incoming mail, reporting calendar commitments, finding files, and writing notes. Messages and events may be processed by a language model that the operator has configured, in order to produce those summaries. No data is used for advertising, profiling, or training a model by this application.

3. Storage and retention

Everything stays on the operator's own computer. OAuth credentials are stored in a local configuration directory with file permissions restricted to the operator's user account. Copies of email or calendar content exist only in local notes and logs the operator chooses to keep, and can be deleted at any time by deleting those files.

4. Sharing

The application does not sell, rent, or share data with third parties. It does not operate a server that receives Google user data. There is no analytics, no tracking, and no advertising in this application or on this website.

5. Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Data obtained through Google APIs is not transferred to others except as necessary to provide the feature the operator requested, is not used for advertising, and is not used to train or improve generalised models.

6. Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions, which immediately invalidates the application's credentials. Local copies can be deleted by removing the application's configuration directory and the notes it produced on the operator's computer. Revoking access requires no request to the operator and no waiting period.

7. Children

The application is not directed at children and has no users other than its operator.
