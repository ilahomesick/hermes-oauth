Hermes Agent

A single-user, self-hosted personal assistant.

This site exists for one reason: to describe the Google Workspace integration of a personal assistant called Hermes Agent, which runs entirely on its owner's own computer. Google requires an application that requests OAuth access to publish a home page, a privacy policy and terms of service, so these pages are public and plainly written.

Who uses it

Exactly one person: the owner of the machine where Hermes Agent runs. There is no sign-up, no account system, no multi-tenant service, and no server in the cloud. The application is not offered to the public and has no users other than its owner.

What it does with Google

With the owner's explicit consent, the assistant reads and sends the owner's own email, reads the owner's own calendar, and reads and writes files in the owner's own Drive, Docs and Sheets, so that it can produce a morning briefing, answer questions about the owner's schedule, and file notes. Nothing is collected from anyone else, and nothing is sent to a third party.

Where data goes

Nowhere. All data stays on the owner's computer. See the privacy policy for the details, including how to revoke access at any time.
